# CSS Quiz: Animations and Effects

A small interactive quiz web application built with plain HTML, CSS, and JavaScript. It tests knowledge of CSS animations, transforms, transitions, and 3D effects through a timed multiple-choice format.

## Overview

This project is a single-page educational game designed to reinforce CSS animation concepts. It presents 12 questions, gives each one a 40-second timer, and awards more points for faster correct answers.

The app features a futuristic neon design, dynamic question flow, score tracking, and a final results screen.

## Features

- 12 timed multiple-choice questions
- 40-second countdown for each question
- Score calculation based on speed and correctness
- Visual feedback for correct and incorrect answers
- Progress bar and question counter
- Final score summary with replay option
- Responsive layout for desktop and mobile devices
- No dependencies or build setup required

## Topics Covered

The quiz includes questions on:

- CSS transforms (`translate`, `rotate`, `scale`, `skew`)
- Units for angles and transformations
- `transition` timing and effects
- `@keyframes` and animation behavior
- Easing functions and natural motion
- 3D perspective and card transforms
- Differences between `transition` and `animation`
- Multiple animation assignments on a single element

## Project Structure

- `index.html` — main HTML file containing the layout, styling, questions, and JavaScript logic
- `README.md` — project documentation

## Run the Project

Open the project in a browser:

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Click the "Почати гру" button to start the quiz.

No server is required because it is a static HTML page.

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Notes

This project is an educational demo and a good example of using native web technologies to build an interactive learning experience without frameworks or external libraries.
